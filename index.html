Air-Gapped Screen-to-Camera Optical File Transfer

Sabrina Shares transports files up to 10 MB across physically isolated devices using a high-frequency cycling stream of fountain-coded QR frames. Completely unidirectional (optical diode). Zero network packets, zero Bluetooth, zero pairing, zero server telemetry, and zero persistent storage.

[ MODE: 02 ] R

Point camera at the transmitting display. The Web Worker peeling engine decodes droplets on the fly, solves missing frames, verifies SHA-256, and terminates scanning automatically.

Run an in-browser virtual optical loopback with 100 KB to 10 MB test files and up to 40% artificial packet drop. Execute the automated cryptographic and fountain test suite.

// WHY SABRINA SHARES IS UNIQUE [ZERO-TRUST]
[ 01. STRICT UNIDIRECTIONAL DIODE ]
Data travels purely by photons emitted from a screen to a camera sensor. There is no radio transmitter, no Wi-Fi handshake, no Bluetooth ping, and no physical medium to carry return packets. Backchannel leakage is mathematically and physically impossible.
[ 02. RATELESS SOLITON FOUNTAIN ]
Unlike normal QR transfers that require ordered frames, Sabrina Shares uses rateless Luby Transform fountain codes. The receiver can start scanning at any second, miss half the frames due to glare or motion blur, and successfully reconstruct the full payload.
[ 03. AUTOMATIC TERMINATION ]
Once all K blocks are reconstructed and the cryptographic SHA-256 matches, the optical decoder immediately cuts the video stream, stops CPU cycles, and presents the completed file download.
[ 04. ZERO-PERSISTENCE RAM HEAP ]
No cookies, no localStorage, no IndexedDB, and no Cache API storage of transferred data. All file chunks live strictly in volatile memory and are zeroed out upon session wipe or file download.
[ 05. MULTI-GRID THROUGHPUT ]
Supports 1x1, 2x2, and 3x3 multi-QR grids per frame. Combined with framerates up to 24 FPS, high-end mobile cameras can capture multiple droplets simultaneously for maximum bandwidth.
[ 06. WEB CRYPTO SHIELD ]
Optional AES-256-GCM encryption with 200,000+ iteration PBKDF2-SHA256 key derivation performed natively in browser WebCrypto with random 128-bit salt and 96-bit IV.
